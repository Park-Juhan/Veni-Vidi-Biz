# 의사결정 모델 조사 및 적용

작성일: 2026-11-09 (한국 시간)

## 문제

1차 프로토타입 테스트 결과, 다섯 모듈이 입력값을 정해진 식에 넣는 계산기에 머물렀다.
이 때문에 "어떤 선택이 더 나은가", "얼마나 위험한가"를 답하지 못했다.
실제 상권·판매 자료는 아직 확보하지 못했다(설계서 6.3, SRS 5). 그래서 아래 조건으로 모델을 골랐다.

- 학습 데이터 없이 사용자 입력과 명시적 가정만으로 동작할 것
- 계산 과정과 근거를 화면에 설명할 수 있을 것 (설계서 7.2)
- 실제 자료가 생기면 가정값을 추정값으로 교체할 수 있을 것
- 외부 라이브러리를 추가하지 않을 것 (Python 표준 라이브러리 `decimal`, `random`, `itertools`)

## 모듈별 후보 비교와 선택

| 모듈 | 검토한 후보 | 선택 | 선택 이유 |
|---|---|---|---|
| 업장 | 가중합(SAW), AHP, **TOPSIS**, ELECTRE | **TOPSIS + 제약 필터 + 민감도 분석** | 비용형(임대료·초기 자금)과 이익형(면적·적합도) 기준을 함께 다룬다. 단위가 다른 기준을 정규화하고 결과를 0~100 근접도로 설명할 수 있다. AHP는 쌍대비교 입력이 15쌍이라 입력 부담이 크고, ELECTRE는 결과 설명이 어렵다. |
| 메뉴 가격 | 원가 가산, 경쟁 가격 비교, **가격탄력성 수요 모델**, 회귀 기반 수요 추정 | **일정 탄력성 수요곡선 + 이익 최대 가격 탐색** | 가격을 올리면 판매량이 줄어드는 효과를 반영해 "이익이 최대가 되는 가격"을 제시한다. 경제학 표준 결과(러너 지수·역탄력성 규칙)로 검증할 수 있다. 회귀 추정은 가격별 판매 기록이 필요해 후속 단계로 둔다. |
| 운영 개선 | 손익분기 분석, 시나리오 분석, **몬테카를로 시뮬레이션**, 시계열 예측 | **몬테카를로 적자 위험 시뮬레이션 + 안전한계율** | 평균 손익만 보던 방식을 "적자가 날 확률"과 "나쁜 달(하위 5%)의 손익"으로 확장한다. 항목별 절감이 위험을 얼마나 줄이는지 같은 난수로 비교할 수 있다. 시계열 예측은 월별 매출 기록이 필요하다. |
| 마케팅 | 규칙 점수, TOPSIS, **0-1 배낭 문제**, 성과 기반 ROI 예측 | **예산·시간 제약 하 채널 조합 최적화 + 광고 손익분기 고객 수** | 한 채널만 고르지 않고, 예산과 시간 안에서 적합도 합이 최대인 조합을 찾는다. 손익분기 고객 수는 성과 자료 없이도 "이만큼 새 고객이 와야 본전"이라는 판단 기준을 준다. ROI 예측은 실제 성과 자료가 필요하다. |
| 재료비 | 단순 원가, **경제적 주문량(EOQ)**, (s, S) 재고 정책 | **EOQ + 보관 가능 기간 상한** | 1회 사용 원가 계산에 더해 "한 번에 얼마씩 주문해야 주문·보관 비용이 최소인가"를 답한다. 확률적 재고 정책은 수요 분포 자료가 필요하다. |

## 적용한 모델

### 1. 업장 — TOPSIS (Hwang & Yoon, 1981)

1. **제약 확인:** 임대료 예산, 필요 면적, 확보 자금. 모두 충족한 후보를 먼저 추천한다.
2. **TOPSIS:** 기준 6개(월 임대료↓, 초기 필요 자금↓, 면적↑, 고객층↑, 동선↑, 시설↑)를 벡터 정규화하고 사용자가 정한 중요도(0~5)로 가중한다.
   근접도 = 반이상해 거리 ÷ (이상해 거리 + 반이상해 거리)이며, 100에 가까울수록 좋다.
3. **민감도 분석:** 각 기준의 중요도를 0과 5로 바꿔 1순위가 달라지는 기준을 알려준다.

구현: `app/common/decision.py` `topsis()`, `app/modules/property/models/decision_engine/engine.py`

### 2. 메뉴 가격 — 가격탄력성 수요 모델

- 수요: Q = Q0 × (P ÷ P0)^(−e). 현재 가격 P0와 판매량 Q0를 기준점으로 쓴다.
- e는 사용자가 고른 가정값이다: 낮음 0.8, 보통 1.5, 높음 2.5.
- 원가 바로 위부터 현재 가격의 2배까지 탐색해 (P − 원가) × Q가 최대인 가격을 찾는다.
- 이론값 원가 × e ÷ (e − 1)과 일치하는지 테스트로 검증한다. 예: 원가 1,500원, e = 2.5이면 2,500원.

### 3. 운영 개선 — 몬테카를로 시뮬레이션

- 매출 ~ 정규분포(표준편차 = 입력 변동성). 재료비는 매출에 비례하고, 나머지 비용은 각각 정규분포를 따른다.
- 4,000개월을 시뮬레이션하고 고정 시드로 재현성을 보장한다.
- 출력은 다음과 같다: 적자 확률(절감 전/후), 하위 5% 월 손익, 항목별로 단독 절감했을 때 적자 확률 감소, 안전한계율.
- 비용 변동성이 0이면 정규분포 이론값 Φ((BEP/R − 1)/σ)와 일치하는지 테스트로 검증한다.

### 4. 마케팅 — 0-1 배낭 문제

- 채널 조합을 전부 열거해(채널 3개 → 7개 조합), 예산·시간 제약을 지키면서 적합 점수 합이 최대인 조합을 고른다. 점수가 같으면 비용이 적은 조합을 우선한다.
- 손익분기 추가 고객 = 비용 ÷ (객단가 × 공헌이익률).

### 5. 재료비 — EOQ (Harris, 1913)

- EOQ = √(2DS/H). D는 월 수요(구매 단위), S는 1회 주문 비용, H는 단가 × 월 보관 비용률이다.
- 보관 가능 기간 × 월 수요를 상한으로 둔다.
- 현재 구매 수량으로 주문할 때와 월 발주·보관 비용을 비교한다.

## 한계와 다음 단계

| 가정값 | 실제 자료가 생기면 바꿀 방법 |
|---|---|
| 업장 적합도(사용자 1~5점) | 상권·유동인구 공공데이터의 지표를 기준값으로 사용 |
| 가격탄력성(선택값) | 가격별 판매 기록으로 로그-로그 회귀를 돌려 e를 추정 |
| 매출·비용 변동성(입력값) | 월별 매출·비용 기록의 표준편차 |
| 마케팅 채널 비용·적합 점수(가상 값) | 실제 견적과 채널별 성과 기록 |
| 재료 수요(월 사용 횟수) | 판매 기록 × 레시피 사용량 |

모든 결과 화면에 모델 이름 배지와 계산식·가정을 표시한다. 가정값은 실제 시장 자료가 아님을 함께 밝힌다.
