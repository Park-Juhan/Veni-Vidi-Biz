## 우선순위별 수정

### 우선: 공개 제외 범위 보강

기존 `.gitignore`는 `.env`만 제외하고 `.env.local` 등 변형과 인증 파일을 충분히 다루지 않았다.
환경 파일, PEM/KEY/P12/PFX, 인증 JSON, SSH 키, AWS·로컬 도구 설정,
개인 사업 자료 경로, IDE, 로그·DB·출력 파일을 제외하도록 확장했다.
가짜 경로를 Git에 전달하는 테스트로 제외 여부를 검증하며 실제 키 파일을 생성하지 않는다.
정상 소스·테스트·CI·설명용 `.env.example`이 제외되지 않는지도 검증한다.

업로드 후보만 임시 폴더로 복사해 실행했다. `.venv`, `tmp`의 PDF 분석 이미지와 QA 화면,
실제 환경 파일 및 원본 문서의 개인 이름·학번은 공개 소스 복사본에 포함하지 않았다.
검사는 현재 파일과 대표 키 패턴에 대한 점검이다. 미래 파일이나 모든 형태의 개인정보를
자동으로 보장하는 도구는 아니므로 업로드 목록의 최종 확인은 필요하다.

### 우선: 숫자 입력의 서버 오류 수정

운영 매출에 `1e-999999999`를 입력하면 기존에는 `decimal.Overflow`가 발생했다.
숫자 입력은 최대 64자, 0이 아닌 값은 1e-28 이상으로 제한하고,
계산 중 `DecimalException`도 사용자 입력 오류로 변환한다.
오류 계산은 Repository에 저장하지 않아 이전 정상 결과를 보존한다.
각 모듈의 HTTP 요청에서 오류 응답 422와 정상 결과 유지를 확인했다.

### 실행·유지보수 보완

- 잘못된 모듈 식별자와 포트는 traceback 대신 argparse의 사용법 안내와 종료 코드 2를 반환한다.
- `.gitattributes`로 소스 파일의 줄바꿈 기준을 명시했다.
- GitHub Actions에 Windows/Ubuntu Python 3.12 설치·의존성 점검·자동 테스트를 구성했다.
- 상대 import와 동적 조립 진입점까지 포함한 구조 검사를 추가했다.
- 반응형 검사에 320px 화면을 추가했다.

## 실행 및 검증

프로젝트 루트에서 실행한다. PowerShell 활성화 스크립트는 필요 없다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

기본 URL은 http://127.0.0.1:5000 이다. 단독 실행 예:

```powershell
.\.venv\Scripts\python.exe run.py --module menu_pricing --port 5001
```

| Git 제외 규칙 | 민감/로컬 가상 경로 제외, 정상 소스 포함 확인 |
| GitHub 원격 CI | 구성만 완료. 아직 push/PR하지 않아 미실행 |

기본 자동 테스트는 표준 `unittest`와 런타임 의존성으로 실행한다. Git 제외 테스트 2개는
Git 설치가 필요하며, Git이 없으면 명시적으로 건너뛴다.
브라우저 검사는 `requirements-dev.txt`와 Chrome이 필요하다. 실행법은 README 참고.
검증용 패키지를 읽을 때 Windows 샌드박스 권한 제한이 있었으나, 동일 복사본·환경을
권한이 허용된 실행에서 재검증해 통과했다. 프로젝트 코드의 실행 오류와 구분했다.

## GitHub 업로드 전 확인할 사항

프로젝트 루트는 아직 Git 저장소로 초기화하지 않았다. 실제 커밋·원격 연결·업로드도 수행하지 않았다.
Git으로 업로드할 경우 초기화 후 `git status --short --ignored`와 `git add --dry-run .`로 대상을 확인한다.
웹 업로드는 `.gitignore`를 자동 필터로 쓰지 않으므로 폴더 전체를 그대로 올리지 않는다.
이미 추적한 파일·과거 커밋에는 `.gitignore`가 소급 적용되지 않는다.

실제 비밀키는 기본 코드에 하드코딩하지 않고 프로세스 시작 시 생성한다.
테스트의 `test-only` 문자열은 테스트 앱에서만 사용하는 공개 테스트 값이다.
`.env.example`을 추가한다면 자리표시자만 작성한다. `.env` 자동 로딩은 구현하지 않았다.
개인 자료·외부 문서를 추가할 때 개인정보와 사용 권한을 확인한다.
프로젝트 재사용 라이선스는 아직 지정하지 않았다.
